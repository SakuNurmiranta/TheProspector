## Game Idea
# Exercise

*(Also found in presentation slides)*

## Task

1. **Choose a Game Engine**
    - Install a game engine of your choice unless you already have one.

2. **Initial Planning**  
   Alone or as part of a group, create an initial plan for:
    - A game.
    - Or a feature of a game where **networking** plays a significant role as:
        - **Problem Source**, or
        - **Enabling a Feature/Functionality**.

3. **Utilize Existing Projects**
    - You may use an existing game project to:
        - Expand it with a network feature, or
        - Fix a problem in the existing networking functionality.
    - The same game can be used for future course projects.

4. **Flexibility**
    - You can change the target game or plan later if needed, so avoid over-analyzing or hesitating at this stage.

---

## Instructions

1. **Describe the Game Briefly**
    - Outline the genre, gameplay, objectives, etc.
    - Focus specifically on the online/networking-related features.

2. **Present Results**
    - At the end of the session, present the group's results up to that point.
