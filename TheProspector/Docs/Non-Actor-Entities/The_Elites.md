## DESIGN REFERENCE: The Elites

**Elite** class instance is a GameEntity derivative that represents a metal head whose opinions are objectively correct. 
It carries three lists that get updated as the instance meets tracks or albums in its life cycle. One list is for bands it wants to follow, 
one is for bands it deems unworthy, and one is for bands that it prefers to actively avoid. Besides this, an instance of Elite has a method
that gives points tracks that meets the instances criteria for good music.
